# pure-nvim in one file

`init.lua` is the whole [pure-nvim](https://github.com/MiaSchionato/pure-nvim)
configuration (the `windows` branch, which also works on Linux and macOS) in
a single file. Generated by `scripts/bundle.lua`; do not edit it here.

## Install

Clone this branch as Neovim's config folder:

```sh
# Linux / macOS
git clone -b single-file --depth 1 https://github.com/MiaSchionato/pure-nvim ~/.config/nvim
```

```powershell
# Windows
git clone -b single-file --depth 1 https://github.com/MiaSchionato/pure-nvim $env:LOCALAPPDATA\nvim
```

The folder must not exist yet: move an old configuration away first
(`mv ~/.config/nvim ~/.config/nvim.old`). Then just run `nvim`.

**Update:** `git pull` in that folder.

**Try without installing:** from any folder with this file,
`nvim -u init.lua`.

## What works

**Portable by default:** no plugins or extra themes are downloaded. The
home-made modules (pickers, markdown, key hints, git, Todoist, notes), the
language servers installed on the machine and the NeoSolarized (default,
embedded with its Apache-2.0 license) and myghtfly themes work. Put
`vim.g.pure_portable = false` near the top of `init.lua` to install and load
everything.

The pickers need `fzf`, `fd`, `rg` and `bat`; on Debian and Ubuntu the
packages install the last two as `fdfind` and `batcat`, which are found as
well. Tested on Windows and on Ubuntu; on macOS the file explorer uses its
BSD `ls`.

Documentation: `<leader>fh` inside Neovim, or the `docs/` folder of the main
repository.

## Rebuilding this branch

From a checkout of `windows`:

```sh
nvim -l scripts/bundle.lua        # writes pure.lua (never init.lua there)
```

then copy that file here as `init.lua` and commit it.
