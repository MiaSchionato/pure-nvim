# pure-nvim in one file

`pure.lua` is the whole [pure-nvim](https://github.com/MiaSchionato/pure-nvim)
configuration (the `windows` branch, which also works on Linux and macOS) in
a single file. Generated by `scripts/bundle.lua`; do not edit it here.

```sh
curl -LO https://raw.githubusercontent.com/MiaSchionato/pure-nvim/single-file/pure.lua
nvim -u pure.lua            # try it
```

Or save it as `~/.config/nvim/init.lua` (`%LOCALAPPDATA%\nvim\init.lua` on
Windows) to use it as the configuration.

**Portable by default:** no plugins or extra themes are downloaded. The
home-made modules (pickers, markdown, key hints, git, Todoist, notes), the
language servers installed on the machine and the myghtfly theme work. Put
`vim.g.pure_portable = false` near the top of the file to install and load
everything. The pickers need `fzf`, `fd`, `rg` and `bat`.

Documentation: `<leader>fh` inside Neovim, or the `docs/` folder of the main
repository.

To update this branch, from a checkout of `windows`:

```sh
nvim -l scripts/bundle.lua        # writes pure.lua
```

and commit that file here.
